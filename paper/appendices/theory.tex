\section{Theory}
\label{app:theory}

This appendix contains additional details on the formal specification
and proofs in $\cj$\!.


\subsection{Definitions}
\label{app:theory-def}

\subsubsection{Syntax}

There is an additional expression in the syntax not mentioned
in the main text, an error expression which is convenient for the proofs but not necessary
for introducing $\cj\!$. Similarly, there is a syntax for \textit{values},
used in the formal specification of evaluation.

\[
\begin{aligned}[t]
 \nb{e} \,\,\,\coloneqq
	 \ & \ \ \ \cdots &&\t{}\\
     &\mid \nb{\t{error}} &&\t{error}\\
     & 
\end{aligned}
\qquad\qquad
\begin{aligned}[t]
 \nb{v} \,\,\,\coloneqq
	 &\ \ \ \unit && \t{unit}\\
	 &\mid \nb{\inj{i}{v}} && \t{injection}\\
	 &\mid \nb{(e_1,e_2)} && \t{tuple}\\
	 &\mid \nb{\dict{v_1}{v_2}} &&\t{dictionary}\\
	 &\mid \nb{\t{error}} &&\t{error}
 \end{aligned}
\]



\subsubsection{Evaluating}

There are also additional evaluation rules not mentioned in the main text, again
useful for proofs but unnecessary for introducing $\cj$\!.

\begin{center}
\AxiomC{}
\UnaryInfC{$\step{v}{v}$}
\DisplayProof
\qquad
\AxiomC{$\step{e}{\t{error}}$}
\UnaryInfC{$\step{E[e]}{\t{error}}$}
\DisplayProof
\end{center}

The $\nb{E}$ is an \textit{evaluation context} \citep{pierce2002types}. It allows us to
succinctly specify that if a subexpression evaluates to $\error$, then the whole expression evaluates
to $\error$. The other rule simply says values evaluate to themselves.
In the main text the lookup rule uses an operator $\nb{{\large \sqcap}_\mathcal{V}}$,
which we define below.

\[
\begin{aligned}
{\large \nb{\sqcap}}_\mathcal{\nb{\emp}} &= \error\\
{\large \nb{\sqcap}}_\mathcal{\nb{V}} &= 
\nb{v_1 \sqcap v_2 \sqcap \cdots \sqcap v_n} \;\t{for all }\nb{v} \in \nb{\mathcal{V}}
\end{aligned}
\]

The operator $\nb{{\large \sqcap}_\mathcal{V}}$ just generates a nondeterministic
choice across all elements of $\nb{\mathcal{V}}$, and if it is empty returns $\error$.

\paragraph{Derivation of $\es\bstep\vs$}
The derivation $\der$ associated with $\es\bstep \vs$ represents \textit{the execution trace}. This
is an important technical detail in our compiler correctness proofs.
\[
\es \bstep_\nb{D}\vs \iff \nb{D} \text{ is a derivation of }\es \bstep \vs
\]


\subsection{Typing}

The typing relation identifies expressions in $\cj$\! with behavior. It is a cornerstone of the 
theory, as it allows us to consider in our proofs all possible program behaviors of interest.

\DisplayProof
\quad\quad
\AxiomC{}
\UnaryInfC{$\p{\emp} {\unit} {\Unit}$}
\DisplayProof
\quad\quad
\AxiomC{}
\UnaryInfC{$\p{\D} {\t{error}} {\ty}$}
\DisplayProof
\quad\quad
\AxiomC{$\p{\D}{e}{\ty_i}$}
\UnaryInfC{$\p{\D} {\inj{i}{e}} {\ty_1 \+ \ty_2}$}
\DisplayProof
\end{center}

\TrinaryInfC{$\p{\D_\t{kv} \o \D_\t{q}} {e_\t{kv}(e_\t{q})_\mathcal{R}} {\ty_\t{v}}$}

\end{center}

\DisplayProof
\end{center}

Some rules reference an $\nb{\t{enum}}$ relation, which just checks that types are of 
the form $\nb{\Unit \+ \Unit \+ \cdots \+ \Unit}$.

\subsubsection{Source environment}

Source environments specify valid substitutions for expressions with free variables. Essentially these substitutions
say that a free variable must be substituted by a value of the correct type (e.g., $\nb{x+2}$ requires a numeric value
for $\nb{x}$ to make sense).

\begin{center}
\AxiomC{}
\UnaryInfC{$\nb{\emp} \vdash \nb{\emp}$}
\DisplayProof
\quad\quad
\AxiomC{$\nb{\D}\-\nb{\nv}$}
\AxiomC{$\p{\emp}{v}{\ty} $}
\BinaryInfC{$\nb{\D,\bind{x}{\ty}} \vdash \nb{\nv\{x \map v\}}$}
\DisplayProof
\end{center}

\subsection{Compiling}

\paragraph{Compiling types} An important detail on compiling is how we compile \textit{types}, which constrain the domain and codomain
of the compiled $\rd{k}$-linear maps. Because compiling dictionaries involves an inner product, types must
compile to inner product spaces \citep{axler2024linear}. The inner product in each case is always the Frobenius
inner product, which generalizes the usual inner product on $\rd{\R^n}$ to vector
spaces of linear maps.

\[
\begin{aligned}
\c{\nb{\_}}: \nb{\t{Type}} \to & \;\rd{\t{Inner Product Space}}\\\\
\cm{\Unit} &= \rd{\R}\\
\c{\nb{\ty_1 \+ \ty_2}} &= \c{\nb{\ty_1}} \,\rd{\+}\,\c{\nb{\ty_2}}\\
\c{\nb{\ty_1 \x \ty_2}} &= \c{\nb{\ty_1}} \,\rd{\x}\,\c{\nb{\ty_2}}\\
\c{\nb{\ty_\t{k} \Map \ty_\t{v}}} &= \rd{\t{Lin}}(\c{\nb{\ty_\t{k}}} ,\c{\nb{\ty_\t{v}}})\\
\end{aligned}
\]

The operator $\rd{\+}$ denotes the direct sum of vector spaces, $\rd{\x}$ the direct product, and
$\rd{\t{Lin}}(\rd{A},\rd{B})$ the space of linear maps $\rd{f}$: $\rd{A} \to \rd{B}$.

\paragraph{Compiling contexts}
Contexts control the domain of the compiled $\rd{k}$-linear maps. A context with $\rd{k}$
free variables is denoted by a $\rd{k}$-tuple of vectors drawn from the vector spaces denoted
by their types.

\[
\begin{aligned}
\c{\nb{\_}}: \nb{\t{Context}}   \to &\;\rd{\t{Tuple}}(\rd{\t{Vector}})\\\\
\c{\nb{\emp}} &= \rd{\{0\}}\\
\c{\nb{\D,\bind{x}{\ty}}} &= \c{\nb{\D}}\,\rd{\x}\,\c{\nb{\ty}}\\
\end{aligned}
\]

\paragraph{Compiling programs}

There is one additional rule for compiling programs, for compiling \error. It just returns 
the $\rd{0}$ vector from the vector space denoted by its type.

\[
\c{\p{\D}{\t{error}}{\ty}}(\svec) =\rd{0}_{[\hspace{-.18em}[\nb{\ty}]\hspace{-.18em}]}
\]


\subsection{Proofs}
\label{app:theory-proofs}

The following proofs assume Barendregt's convention \citep{pierce2002types}, which states that
variable names across bound and free variables are unique. This greatly simplifies proofs in a setting
where binding mechanisms are not complicated. We additionally reference substitution $\nb{x \map v}(e)$
throughout the proofs---it is no more than replacing all instances of $\nb{x}$ with $\nb{v}$ in the expression
$\nb{e}$ \citep{pierce2002types}.

\subsubsection{Theorem (Programs have behavior).}
\t{If $\p{\D}{e}{\ty}$ and $\D\vdash\nv$, then}
\[
\exists \vs, \nv(\es) \bstep \vs
\]
\t{\textbf{Proof.}} By induction on $\p{\D}{e}{\ty}$,
\begin{itemize}
\item \t{\textbf{Case}} $\p{\emp}{\unit}{\Unit}$

Let $\exists \vs = \unit$

By evaluation $\unit \bstep \unit$
\item \t{\textbf{Case}} $\p{\D}{\error}{\ty}$

Let $\exists \vs = \error$

By substitution and evaluation $\nv(\error)=\error \bstep \error$
\item \t{\textbf{Case}} $\p{\bind{x}{\ty}}{x}{\ty}$

By assumption $\nb{\bind{x}{\ty}}\vdash \nb{\{x \map v\}}$ where $\vs :\nb{\ty}$

Let $\exists \vs= \nv(\xs)$

By substitution and evaluation $\nv(\xs)=\vs\bstep \vs$
\item \t{\textbf{Case}} $\p{\D}{\inj{1}{e}}{\ty_1 \+ \ty_2}$

By induction $\nv(\es) \bstep \vsrc1$

Let $\exists \vs=\inj{1}{v_1}$

By substitution and evaluation $\nv(\inl{e})=\inj{1}{\nv(e)} \bstep \inj{1}{v_1}$
\item \t{\textbf{Case}} $\p{\D}{\inj{2}{e}}{\ty_1 \+ \ty_2}$

Similar to previous case
\item \t{\textbf{Case}} $\p{\D}{(e_1,e_2)}{\ty_1 \x \ty_2}$

Let $\exists \vs=\nb{(\nv(\ess1),\nv\nb(\ess2))}$

By substitution and evaluation $\nv(\nb{(\ess1,\ess2)})=\nb{(\nv(e_1),\nv(e_2))} \bstep \nb{(\nv(e_1),\nv(e_2))}$
\item \t{\textbf{Case}} $\p{\D_1 \o \D_2}{\dict{e_1}{e_2}}{\ty_1 \Map \ty_2}$

By splitting source environments $\nv=\nvs1 \o \nvs2$ where $\Ds1 \vdash \nvs1$ and $\Ds2 \vdash \nvs2$

By induction and substitution $\nvs1(\ess1) = \nv(\ess1)\bstep \vsrc1$

By induction and substitution $\nvs2(\ess2) = \nv(\ess2)\bstep \vsrc2$

Let $\exists \vs=\dict{\vsrc1}{\vsrc2}$

By substitution and evaluation $\nv(\dict{e_1}{e_2})=\dict{\nv(e_1)}{\nv(e_2)}=\dict{\nvs1(e_1)}{\nvs2(e_2)} \bstep \dict{v_1}{e_2}$
\item \t{\textbf{Case}} $\p{\D_1 \o \D_2}{\letb{x}{e_1}{e_2}}{\ty_2}$

By splitting source environments $\nv=\nvs1 \o \nvs2$ where $\Ds1 \vdash \nvs1$ and $\Ds2 \vdash \nvs2$

By induction and substitution $\nvs1(\ess1) = \nv(\ess1) \bstep \vsrc1$

By source environments $\nb{\Ds2,\bind{x}{\ty_1}} \- \nb{\nvs2\{x \map v_1\}}$

By induction and substitution $\nb{\nvs2\{x \map v_1\}}(\ess2)=  \nb{\nv\{x \map v_1\}}(\ess2)\bstep \vsrc2$

Because substitutions commute $\nb{\{x \map v_1\}}(\nb{\nv}(\ess2))\bstep \vsrc2$

Let $\exists \vs = \vsrc2$

By substitution and evaluation $\nv(\letb{x}{e_1}{e_2})=(\letb{x}{\nvs1(e_1)}{\nvs2(e_2)}) \bstep \vsrc2$
\item \t{\textbf{Case}} $\p{\D_1 \o \D_2}{\sume{e}{x_1}{e_1}{x_2}{e_2}}{\ty}$

By splitting source environments $\nv=\nvs1 \o \nvs2$ where $\Ds1 \vdash \nvs1$ and $\Ds2 \vdash \nvs2$

By induction and substitution $\nvs1(\es) = \nv(\es) \bstep \vs$

Because evaluation preserves typing and by closing substitutions $\vs:\nb{\ty_1 \+ \ty_2}$

By canonical forms either $\vs=\inl{v_1}$ or $\vs=\inr{v_2}$

Consider each possibility,
\begin{itemize}
\item \t{\textbf{Case}} $\vs=\inl{v_1}$

By source environments $\nb{\Ds2,\bind{x}{\ty_1}} \- \nb{\nvs2\{x \map v_1\}}$

By induction and substitution $\nb{\nvs2\{x \map v_1\}}(\ess1)=\nb{\nv\{x \map v_1\}}(\ess1) \bstep \vsrc{\bullet}$

Because substitutions commute $\nb{\{x \map v_1\}}(\nb{\nv}(\ess1)) \bstep \vsrc{\bullet}$

Let $\exists \vs=\vsrc\bullet$

By substitution and evaluation $\nb{\sume{\nv(e)}{x_1}{\nv(e_1)}{x_2}{\nv(e_2)}} \bstep \vsrc\bullet$
\item \t{\textbf{Case}} $\vs = \inr{v_2}$

Similar to previous case
\end{itemize}
\item \t{\textbf{Case}} $\p{\D}{\pi_1e}{\ty_1}$

By induction $\nv(\es) \bstep \vs$

Because evaluation preserves typing and by closing substitutions $\vs:\nb{\ty_1 \x \ty_2}$

By canonical forms $\vs=\nb{(v_1,v_2)}$

Let $\exists \vs=\vsrc1$

By substitution and evaluation $\nv(\nb{\pi_1e})=\nb{\pi_1\nv(e)} \bstep \vsrc1$
\item \t{\textbf{Case}} $\p{\D}{\pi_2e}{\ty_2}$

Similar to previous case
\item \t{\textbf{Case}} $\p{\D}{e_1 \sqcap e_2}{\ty}$

By induction $\nv(\ess1) \bstep \vsrc1$

By induction $\nv(\ess2) \bstep \vsrc2$

Let $\exists \vs=\vsrc1$

By substitution and evaluation $\nv(\nb{e_1 \sqcap e_2})=\nb{\nv(\ess1) \sqcap \nv(\ess2)} \bstep \vsrc1$
\item \t{\textbf{Case}} $\p{\D_\t{kv} \o \D_\t{q}}{e_\t{kv}(e_\t{q})_\mathcal{R}}{\ty_\t{v}}$

By splitting source environments $\nv=\nvs{\t{kv}} \o \nvs{\t{q}}$ where $\Ds{\t{kv}} \vdash \nvs{\t{kv}}$ and $\Ds{\t{q}} \vdash \nvs{\t{q}}$

By induction and substitution $\nvs{\t{kv}}(\ess{\t{kv}})=\nv(\ess{\t{kv}}) \bstep \vsrc{\t{kv}}$

By induction and substitution $\nvs{\t{q}}(\ess{\t{q}})=\nv(\ess{\t{q}}) \bstep \vsrc{\t{q}}$

Let $\nb{\mathcal{V}} = \{\nb{(v_\t{v})_i} \mid (\nb{e_\t{q}},\nb{(e_\t{k})_i}) \in \nb{\mathcal{R}}\}$

Consider whether $\mathcal{\nb{V}}$ is empty,
\begin{itemize}
\item \t{\textbf{Case}} $\nb{\mathcal{V}}=\nb{\emp}$

By nondeterministic summation ${\Large \sqcap}_\nb{\emp}=\nb{\t{error}}$

Let $\exists \vs=\nb{\t{error}}$

By evaluation $\nb{\t{error}} \bstep \nb{\t{error}}$

By substitution and evaluation $\nv(\ess{\t{kv}}(\ess{\t{q}})_{\nb{\mathcal{R}}})=\nvs{\t{kv}}(\ess{\t{kv}})(\nvs{\t{q}}(\ess{\t{q}}))_{\nb{\mathcal{R}}} \bstep \nb{\t{error}}$
\item \t{\textbf{Case}} $\nb{\mathcal{V}} \neq \nb{\emp}$

Let $\vsrc{\t{r}} \in \nb{\mathcal{V}}$

Let $\exists \vs = \vsrc{\t{r}}$

Because nondeterministic sums of values return any summand ${\Large \sqcap}_\nb{\mathcal{V}}\,\vs \bstep \vsrc{\t{r}}$

By substitution and evaluation $\nv(\ess{\t{kv}}(\ess{\t{q}})_{\nb{\mathcal{R}}})=\nv(\ess{\t{kv}})(\nv(\ess{\t{q}}))_{\nb{\mathcal{R}}} \bstep \vsrc{\t{r}}$
\end{itemize}
\end{itemize}

\[
\blacksquare
\]


\subsubsection{Theorem (Compiler preserves program behavior)}
\t{If $\p{\D}{e}{\ty}$ and $\D \vdash \nv$ and $\nb{V}=\{(\nb{D},\vs) \mid \nv(\es) \bstep_\nb{D} \vs\}$,}
\[
\cm{e}(\cm{\nv})=\rd{\sum_{\bl{(\nb{D}\hspace{.05em},\hspace{.05em}\vs)\in\nb{V}}}}\,\cm{v}
\]

\t{\textbf{Proof.}} By induction on $\p{\D}{e}{\ty}$
\begin{itemize}
\item \t{\textbf{Case}} $\p{\bind{x}{\ty}}{x}{\ty}$

\t{\textbf{Show}} $\cm{x}(\cm{v})=\rsum_{(\der,\,\vs)\in\Vs}\cm{v}$

By assumption $\nb{\bind{x}{\ty}}\vdash\nb{\{x \map v\}}$

By assumption $\Vs=\{(\der,\vs) \mid \nb{\{x \mapsto v\}(x)} \bstep \vs\}$
\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{x}(\cm{v}) \\[.2em]
		        &= \cm{v} && \t{By compiling}\\[.2em]
		        &= \rsum_{(\der,\,\vs)\in\Vs}\cm{v} && \t{Because }\Vs=\{(\der,\vs)\}\\
\end{aligned}
\]
\item \t{\textbf{Case}} $\p{\emp}{\unit}{\Unit}$

\t{\textbf{Show}} $\cm{\unit}=\rsum_{(\der,\,\unit)\in\Vs}\cm{\unit}$

By assumption $\Vs=\{(\der,\unit) \mid \unit \bstep \unit\}$
\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{\unit} \\[.2em]
		        &= \rsum_{(\der,\,\unit)\in\Vs}\cm{\unit} && \t{Because }\Vs=\{(\der,\unit)\}
\end{aligned}
\]
\item \t{\textbf{Case}} $\p{\D}{\t{error}}{\ty}$

\t{\textbf{Show}} $\cm{\t{error}}(\cm{\nv})=\rsum_{(\der,\,\nb{\t{error}})\in\Vs}\cm{\t{error}}$

By assumption $\Vs=\{(\der,\nb{\t{error}}) \mid \error \bstep \error\}$
\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{\error}(\cm{\nv})\\[.2em]
		        &= \rsum_{(\der,\,\error)\in\Vs}\cm{\error} && \t{Because }\Vs=\{(\der,\error)\}
\end{aligned}
\]
\item \t{\textbf{Case}} $\p{\D}{\inj{1}{e}}{\ty_1 \+ \ty_2}$

\t{\textbf{Show}} $\cm{\inj{1}{e}}(\cm{\nv})=\rsum_{(\der,\,\vs)\in\Vs}\cm{\vs}$

By assumption $\nb{V}=\{(\nb{D},\vs) \mid \nv(\inj{1}{e})=\inj{1}{\nv(e)}\bstep_\nb{D}\vs\}$

Let $\nb{\bar{V}}=\{(\nb{\bar{D}},\nb{\bar{\vs}}) \mid \nv(\es) \bstep_\nb{\bar{D}}\nb{\bar{\vs}}\}$ by inversion on derivations in $\nb{V}$

Observe that $(\nb{D},\vs) \in\Vs \iff (\nb{\bar{D}},\nb{\bar{v}})\in \nb{\bar{V}}$ when $\nb{\bar{D}}$ is obtained by inversion on $\nb{D}$

\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{\inj{1}{e}}(\cm{\nv}) \\[.2em]
		        &= \rd{(}\cm{e}\rd{,0)} && \t{By compiling}\\[.2em]
		        &= \rd{(}\rd{\sum}_{(\nb{\bar{D}},\,\nb{\bar{v}})\in\nb{\bar{V}}}\cm{\bar{v}}\rd{,0)} && \t{By induction}\\[.2em]
		        &=\rd{\sum}_{(\nb{\bar{D}},\,\nb{\bar{v}})\in\nb{\bar{V}}} \rd{(}\cm{\bar{v}}\rd{,0)} && \t{Because }\rd{(a+b,0)}=\rd{(a,0)+(b,0)}\\[.2em]
		        &=\rd{\sum}_{(\nb{D},\,\vs)\in\nb{V}} \rd{(}\cm{v}\rd{,0)} && \t{Because }(\nb{D},\vs) \in\Vs \iff (\nb{\bar{D}},\nb{\bar{v}})\in \nb{\bar{V}}\\[.2em]
		        &=\rd{\sum}_{(\nb{D},\,\vs)\in\nb{V}} \cm{\inj{1}{v}} && \t{By compiling}\\
\end{aligned}
\]
\item \t{\textbf{Case}} $\p{\D}{\inj{2}{e}}{\ty_1 \+ \ty_2}$

Similar to previous case
\item \t{\textbf{Case}} $\p{\D}{(e_1,e_2)}{\ty_1 \x \ty_2}$

\t{\textbf{Show}} $\cm{(e_1,e_2)}(\cm{\nv})=\rsum_{(\der,\,\nb{\nv(e_1,e_2)})\in\Vs}\cm{\nv(e_1,e_2)}$

By assumption $\nb{V}=\{(\nb{D},\nb{(e_1,e_2)}) \mid \nv(\nb{(e_1,e_2)})=\nb{(\nv(e_1),\nv(e_2))}\bstep_\nb{D}\nb{(\nv(e_1),\nv(e_2))}\}$

Observe that $\Vs=\{(\der,\nb{(\nv(e_1),\nv(e_2))}\}=\{(\der,\nb{\nv(e_1,e_2)})\}$
\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{(e_1,e_2)}(\cm{\nv}) \\[.2em]
		        &= \cm{\nv(e_1,e_2)} && \t{Because compiling commutes with substitution}\\[.2em]
                &= \rsum_{(\der,\,\nb{\nv(e_1,\,e_2)})\in\Vs}\cm{\nv(e_1,\,e_2)} && \t{Because }\Vs=\{(\der, \nb{\nv(e_1,e_2)})\}\\
\end{aligned}
\]
\item \t{\textbf{Case}} $\p{\Ds{\t{k}}\o\Ds{\t{v}}}{\dict{e_\t{k}}{e_\t{v}}}{\ty_\t{k} \Map \ty_\t{v}}$

\t{\textbf{Show}} $\cm{\dict{e_\t{k}}{e_\t{v}}}(\cm{\nv})=\rsum_{(\der,\,\dict{v_\t{k}}{v_\t{v}})\in\Vs}\cm{\dict{v_\t{k}}{v_\t{v}}}$

By assumption $\nb{V}=\{(\nb{D},\dict{v_\t{k}}{v_\t{v}}) \mid \nv(\dict{e_\t{k}}{e_\t{v}})\bstep_\nb{D}\dict{v_\t{k}}{v_\t{v}}\}$

Let $\nb{\vsrc{\t{k}}}=\{(\nb{\ders{\t{k}}},\vsrc{\t{k}}) \mid \nv(\ess{\t{k}}) \bstep_\nb{\ders{\t{k}}}\vsrc{\t{k}}\}$ by inversion on derivations in $\nb{V}$

Let $\nb{\vsrc{\t{v}}}=\{(\nb{\ders{\t{v}}},\vsrc{\t{v}}) \mid \nv(\ess{\t{v}}) \bstep_\nb{\ders{\t{v}}}\vsrc{\t{v}}\}$ by inversion on derivations in $\nb{V}$

Observe that $(\nb{D},\dict{v_\t{k}}{v_\t{v}}) \in\Vs \iff (\nb{\ders{\t{k}}},\vsrc{\t{k}})\in \vsrc{\t{k}} \;\land\; (\nb{\ders{\t{v}}},\vsrc{\t{v}})\in \vsrc{\t{v}}$ when $\nb{\ders{\t{k}}}$ and $\ders{\t{v}}$ are obtained by inversion on $\nb{D}$

\[
\begin{aligned}
                &\,\,\;\;\;\, \cm{\dict{e_\t{k}}{e_\t{v}}}(\cm{\nv}) \\[.2em]
		        &=\Bigl(\xvec_\rd{\t{q}} \,\,\rd{\mapsto}\,\,\rsum_{\rd{i=1}}^\nb{n}\,\rd{\langle}\cm{\ess{\t{k}}}_\rd{i}\rd{,\,\xvec_\t{q}\rangle} \rt \cm{\ess{\t{v}}}_\rd{i}\Bigr) && \t{By compiling}\\[.2em]
		        &= \Bigl(\xvec_\rd{\t{q}} \,\,\rd{\mapsto}\,\,\rsum_{\rd{i=1}}^\nb{n}\,\rd{\langle}\rsum_{(\ders{\t{k}},\vsrc{\t{k}})\in\vsrc{\t{k}}}\cm{\vsrc{\t{k}}}_\rd{i}\rd{,\,\xvec_\t{q}\rangle} \rt \Bigl(\rsum_{(\ders{\t{v}},\vsrc{\t{v}})\in\vsrc{\t{v}}}\cm{\vsrc{\t{v}}}_\rd{i}\Bigr)\Bigr) && \t{By induction}\\[.2em]
		        &= \rsum_{(\ders{\t{k}},\vsrc{\t{k}})\in\vsrc{\t{k}}}\rsum_{(\ders{\t{v}},\vsrc{\t{v}})\in\vsrc{\t{v}}}\Bigl(\xvec_\rd{\t{q}} \,\,\rd{\mapsto}\,\,\rsum_{\rd{i=1}}^\nb{n}\,\rd{\langle}\cm{\vsrc{\t{k}}}_\rd{i}\rd{,\,\xvec_\t{q}\rangle} \rt \cm{\vsrc{\t{v}}}_\rd{i}\Bigr) && \\
                & \;\;\;\;\;\t{Because }\cm{\dict{e_\t{k}}{e_\t{v}}}\t{ is linear in } \cm{e_\t{k}} \t{ and }\cm{e_\t{v}}\\[.2em]
		        &=\rd{\sum}_{(\nb{D},\,\dict{v_\t{k}}{v_\t{v}})\in\nb{V}}  \Bigl(\xvec_\rd{\t{q}} \,\,\rd{\mapsto}\,\,\rsum_{\rd{i=1}}^\nb{n}\,\rd{\langle}\cm{\vsrc{\t{k}}}_\rd{i}\rd{,\,\xvec_\t{q}\rangle} \rt \cm{\vsrc{\t{v}}}_\rd{i}\Bigr) && \\
                & \;\;\;\;\;\t{Because }(\nb{D},\dict{v_\t{k}}{v_\t{v}}) \in\Vs \iff (\nb{\ders{\t{k}}},\vsrc{\t{k}})\in \vsrc{\t{k}} \;\land\; (\nb{\ders{\t{v}}},\vsrc{\t{v}})\in \vsrc{\t{v}}\\[.2em]
		        &=\rd{\sum}_{(\nb{D},\,\dict{v_\t{k}}{v_\t{v}})\in\nb{V}} \cm{\dict{v_\t{k}}{v_\t{v}}} && \t{By compiling}\\

\subsubsection{Lemma ($\nb{\mathcal{R}}$ is implemented by $\rd{\langle\_,\_\rangle}$)}
\t{If $(\vsrc{\t{k}})_\nb{i}:\nb{\t{enum}}(\nb{\ty_{\t{k}}})$ and $\vsrc{\t{q}}:\nb{\t{enum}}(\nb{\ty_{\t{q}}})$, then}
\begin{itemize}
\item $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \in\nb{\mathcal{R}} \implies \rd{\langle}\cm{v_\t{k}}_\rd{i}\rd{,}\,\cm{\mathcal{R}}(\cm{v_\t{q}})\rd{\rangle}\rt\cm{v_\t{v}}_\rd{i}=\cm{v_\t{v}}_\rd{i}$
\item $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \not\in\nb{\mathcal{R}} \implies \rd{\langle}\cm{v_\t{k}}_\rd{i}\rd{,}\,\cm{\mathcal{R}}(\cm{v_\t{q}})\rd{\rangle}=\rd{0}$
\end{itemize}

\t{\textbf{Proof.}} Consider each implication,
\begin{itemize}
\item \t{\textbf{Case}} $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \in\nb{\mathcal{R}} \implies \rd{\langle}\cm{v_\t{k}}_\rd{i},\cm{R}(\cm{v_\t{q}})\rd{\rangle}\rt\cm{v_\t{v}}_\rd{i}=\cm{v_\t{v}}_\rd{i}$

By assumption $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \in \nb{\mathcal{R}}$

Because $(\vsrc{\t{k}})_\nb{i}:\nb{\t{enum}}(\nb{\ty_{\t{k}}})$, $\cm{(v_\t{k})_i}$ is a one-hot vector, where $\cm{(v_\t{k})_i}_\rd{j}=\rd{1}$

Since all other entries of $\cm{(v_\t{k})_i}_\rd{j}$ are $\rd{0}$, $\rd{\langle}\cm{v_\t{k}}_\rd{i},\cm{R}(\cm{v_\t{q}})\rd{\rangle}=\rd{\langle}\cm{(v_\t{k})_\nb{i}},\cm{R}(\cm{v_\t{q}})\rd{\rangle}=\cm{(v_k)_\nb{i}}_\rd{j}\rt\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}$

Observe that $\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}=\rd{1}$ when $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \in \nb{\mathcal{R}}$
\[
\begin{aligned}
                &\,\,\;\;\;\, \rd{\langle}\cm{v_\t{k}}_\rd{i},\cm{R}(\cm{v_\t{q}})\rd{\rangle}\rt\cm{v_\t{v}}_\rd{i} \\[.2em]
                &= \rd{\langle}\cm{(v_\t{k})_\nb{i}},\cm{R}(\cm{v_\t{q}})\rd{\rangle}\rt\cm{v_\t{v}}_\rd{i}  && \t{By compiling}\\
                &= \cm{(v_k)_\nb{i}}_\rd{j}\rt\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}\rt\cm{v_\t{v}}_\rd{i}  && \t{Because }\cm{(v_\t{k})_i} \t{ is one-hot}\\[.2em]
                &= \rd{1}\rt\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}\rt\cm{v_\t{v}}_\rd{i}  && \t{Because }\cm{(v_\t{k})_i}_\rd{j}=\rd{1}\\[.2em]
                &= \rd{1}\rt\rd{1}\rt\cm{v_\t{v}}_\rd{i}  && \t{Because }\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}=\rd{1}\\[.2em]
                &= \cm{v_\t{v}}_\rd{i}  && \t{By multiplication}\\[.2em]
\end{aligned}
\]
\item \t{\textbf{Case}} $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \not\in\nb{\mathcal{R}} \implies \rd{\langle}\cm{v_\t{k}}_\rd{i}\rd{,}\,\cm{\mathcal{R}}(\cm{v_\t{q}})\rd{\rangle}=\rd{0}$

Similar to previous case but using $\cm{\mathcal{R}}(\cm{v_\t{q}})_\rd{j}=\rd{0}$ when $((\vsrc{\t{k}})_\nb{i},\vsrc{\t{q}}) \notin \nb{\mathcal{R}}$
\end{itemize}
\[
\blacksquare

\subsection{Lemma (Compiler commutes with substitution)}
If $\p{\D,\bind{x}{\ty_1}}{e}{\ty_2}$,
\[
\cm{\{x \map v\}(e)}(\svec)=\cm{e}(\svec,\cm{v})
\]
\t{\textbf{Proof.}} By induction on $\es$. The argument follows a similar structure to the substitution lemma proved in (Velez-Ginorio et al., 2026).
\[
\blacksquare
\]

\paragraph{Lemma (Compiler maps programs to multilinear maps).}
If $\p{\D,\bind{x}{\ty_1}}{e}{\ty_2}$,
\[
\cm{e}(\svec,\a1\rt\xv1\rp\a2\rt\xv2)=\a1\rt\cm{e}(\svec,\xv1)\rp \a2\rt\cm{e}(\svec,\xv2)
\]
\t{\textbf{Proof.}} Immediate from compiler mapping programs to additive and homogeneous maps.
\[
\blacksquare
\]
\paragraph{Lemma (Compiler maps programs to additive maps).}
If $\p{\D,\bind{x}{\ty_1}}{e}{\ty_2}$,
\[
\cm{e}(\svec,\xv1\rp\xv2)=\cm{e}(\svec,\xv1)\rp\cm{e}(\svec,\xv2)
\]
\t{\textbf{Proof.}} By induction on $\nb{e}$,
\begin{itemize}
\item \t{\textbf{Case}} $\ys$

Consider whether $\xs=\ys$,
\begin{itemize}
\item \t{\textbf{Case}} $\xs=\ys$

By inversion $\nb{\D}=\nb{\emp}$
\[
\begin{aligned}
			&\;\;\;\;\;\cm{x}(\xvec\rp\yvec) && \\
			&= \xvec \rp \yvec && \t{By compiling}\\
			&= \cm{x}(\xvec)\rp\cm{y}(\yvec) && \t{By compiling}
		\end{aligned}
\]
\item \t{\textbf{Case}} $\xs \neq \ys$

Vacuous because we assume a contradiction $\p{\D,\bind{x}{\ty_1}}{y}{\ty_2}$
\end{itemize}
\item \t{\textbf{Case}} $\unit$

Vacuous because we assume $\p{\D,\bind{x}{\ty_1}}{\unit}{\ty_2}$
\item \t{\textbf{Case}} $\error$
\[
		\begin{aligned}
			&\;\;\;\;\;\cm{\error}(\svec,\xv1\rp\xv2) && \\
			&= \rd{0} && \t{By compiling}\\
			&= \rd{0} \rp \rd{0} && \t{Because }\rd{0+0=0}\\
			&= \cm{\error}(\svec,\xv1)\rp\cm{\error}(\svec,\xv2) && \t{By compiling}
		\end{aligned}

			&= \xvec_\rd{\t{q}} \,\,\rd{\mapsto}\,\,\rsum_{\rd{i=1}}^\nb{n}\,\rd{\langle}\cm{\ess{\t{k}}}(\sv{\t{k}},\xv1)_\rd{i}\rd{,\,\xvec_\t{q}\rangle}\rt \cm{\ess{\t{v}}}(\sv{\t{v}})_\rd{i} \\[.2em]

\paragraph{Lemma (Compiler maps programs to homogeneous maps).}
If $\p{\D,\bind{x}{\ty_1}}{e}{\ty_2}$,

\cm{e}(\svec,\rd{\alpha\.\xvec})=\rd{\alpha} \rt \cm{e}(\svec,\xvec)
\]
